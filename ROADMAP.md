# TeleShield — Roadmap

> **Status:** UI mockup prototype (Google AI Studio). Not a working app.

## Where this is going

TeleShield is a **design exploration**, not a standalone client. Building a real
Telegram client from this shell would mean grafting an entire MTProto stack
onto it — that already exists as **DZ TG Player** (a Forkgram fork with a real
Telegram engine, native streaming, and TV work in progress).

So the useful future of TeleShield is as a **design reference**:

### Ideas to carry into DZ TG Player
- [ ] Dark security theme (greens/cyans on near-black) → TV theme pass
- [ ] Bottom navigation (Chats / Vault / Watch Media / Insights / Privacy) → TV IA ideas
- [ ] "D-Pad TV Ready" patterns → D-pad focus work
- [ ] Card-based media rows with quality badges (4K/1080p) → TV media UI
- [ ] Burn-timer / vault visual language → future privacy touches

### Not planned
- Real Telegram protocol support in this repo
- Payments / premium billing
- Independent releases

TeleShield stays a sketchbook. The real app is DZ TG Player.
